## 公開前レビューの修正と最終検証

- 敬称付きの元ゲスト名（Aiko様など）が固定文面に残る草案は、公開前の検査で拒否する。

- 未解決の確認事項は入力中の改行・空行を保ち、保存時に1行1件へ正規化する。
