## Official constraints used for this package

The challenge requires a working live URL; an English description; a public
repository with necessary code, assets, instructions, and an open-source
license; and a public YouTube demo under three minutes with audio. The project
must stay available through judging. See the
[official rules](https://webmcp.devpost.com/rules).

Teachback was created during the submission period; the repository history
begins on 2026-08-27. The current package nevertheless documents the exact
recorded-work extension and avoids relying on the historical entry.
